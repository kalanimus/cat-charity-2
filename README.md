# QRKot

QRKot — асинхронное API благотворительного фонда поддержки котиков.

Фонд открывает целевые проекты и принимает пожертвования пользователей.
Поступившие средства автоматически распределяются между открытыми
проектами в порядке их создания.

## Возможности

- регистрация и JWT-аутентификация пользователей;
- создание пожертвований;
- просмотр пользователем собственных пожертвований;
- автоматическое распределение средств по принципу FIFO;
- управление благотворительными проектами суперпользователем;
- автоматическое закрытие полностью профинансированных проектов;
- интерактивная документация Swagger и ReDoc.

## Технологии

- Python 3.12;
- FastAPI;
- FastAPI Users;
- Pydantic;
- SQLAlchemy;
- Alembic;
- SQLite;
- Pytest.

## Локальный запуск

Клонируйте репозиторий и перейдите в его директорию:

```bash
git clone https://github.com/kalanimus/cat-charity-2.git
cd cat-charity-2
```

Создайте виртуальное окружение:

```bash
python -m venv venv
```

Активируйте его в Windows:

```powershell
.\venv\Scripts\Activate
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

Примените миграции:

```bash
alembic upgrade head
```

Запустите приложение:

```bash
uvicorn app.main:app --reload
```

API будет доступно по адресу:

```text
http://127.0.0.1:8000
```

## Документация API

После запуска приложения доступны:

- Swagger UI: http://127.0.0.1:8000/docs
- ReDoc: http://127.0.0.1:8000/redoc

## Основные эндпоинты

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/auth/register` | Регистрация пользователя |
| POST | `/auth/jwt/login` | Получение JWT |
| GET | `/charity_project/` | Получение всех проектов |
| POST | `/charity_project/` | Создание проекта |
| PATCH | `/charity_project/{project_id}` | Изменение проекта |
| DELETE | `/charity_project/{project_id}` | Удаление проекта |
| POST | `/donation/` | Создание пожертвования |
| GET | `/donation/my` | Пожертвования текущего пользователя |
| GET | `/donation/` | Все пожертвования для суперпользователя |
